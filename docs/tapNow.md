### 1、个人体验及技术猜测


![[Pasted image 20260729132717.png]]

上传杯子图 + 说“生成 12s 广告”，没有马上生成，返回一个额度以及要求我补全风格；----断定系统会维护一个逐步补全的规格

- **硬约束**：duration=12s、语言、画幅(9:16/16:9)、是否配音、是否上字幕
- **业务槽位**（常缺）：品牌名/产品名、核心卖点、价格/优惠、CTA、投放平台(TikTok/IG/YouTube)、目标人群、合规/禁词
- **视觉槽位**（来自图像理解）：材质、颜色、是否有 logo、杯型、场景适配（办公/咖啡馆/居家）
- 从用户自然语言 + 画布上下文里提取能填的槽位（比如“12s”“轻松风”“适合上班族”等）。
- **确定性 validator**：根据“要做 12s 可投放广告”的最低可交付标准，列出缺失字段（例如没品牌名就无法做口播/字幕落款；没平台就无法选画幅/节奏）

有额度提醒,应该**Billing/Quota 服务**在旁路工作
- **余额查询**：你当前 credits / Tapies
- **成本预估**：根据 duration、分辨率、模型档位、是否要多版本/多镜头，估一个“最低会扣多少”
- **预占（reserve）**：真正开始跑生成任务前，先预占额度，失败再释放（避免并发跑爆账）

大致流程猜测：

- **System Prompt（隐藏策略）**：产品风格规范、合规规则、不要泄露内部提示、如何提问补槽位、如何估算成本展示方式等
- **Canvas Context**：画布上的图片资产（ID + caption/标签）、已存在节点输出（比如你之前生成的文案/分镜）、用户当前指令
- **Spec Snapshot**：当前已填的结构化 spec（JSON）
- **下游模型 Prompt Template**：把 spec 转换成具体“视频模型/图像模型”的指令（镜头列表、每镜头 prompt、负面词、时长分配等）

### 2 如何落地：(不包括用户管理，提示词管理，API路由)
核心MVP路径：**对话收集参数 → 调度 AI 模型 → 返回视频**

```
用户输入层
├─ 无限画布（Canvas）
├─ 图片上传（多个）
├─ 提示词/脚本（文本）
├─ 模特图片
└─ 场景图片

处理层
├─ 图像预处理
├─ 提示词解析
├─ 模型编排
└─ 生成调度

输出层
└─ 视频生成 & 输出
```


| 层级       | 选择                            | 原因        |
| -------- | ----------------------------- | --------- |
| **前端**   | React/Vue3 + Canvas/Fabric.js | 无限画布需求    |
| **后端**   | go/java/rust                  | 异步处理，流式响应 |
| **存储**   | S3/OSS                        | 大文件存储     |
| **消息队列** | Redis/RabbitMQ                | 任务队列      |
| **AI模型** | Diffusion/LLM API/seedence    | 视频生成      |
| **数据库**  | PostgreSQL + MongoDB          | 结构化+非结构化  |

### 3、同类竞品参考
>Runway 
  是 TapNow 最直接的竞品。两者都是专业级工具，核心区别在于：Runway 是一个内嵌了 AI 功能的视频编辑器，而 TapNow 是一个内嵌了合成能力的创作画布。Runway 更适合你已经有素材需要编辑和增强的场景；TapNow 则更适合从零开始生成内容并反复调整方向的场景

>Framia Pro 是与 TapNow 理念最接近的竞品之一，它同样采用 AI Agent 驱动方式（广告 Agent、电影 Agent、短视频 Agent、电商 Agent 等）在单一交互画布上运行 [体感还可以]

>Krea 的核心卖点非常贴近“画布式创作”，尤其是它的 **Realtime** 系列：官方介绍里明确提到可以在画布上画、移动对象，然后 AI **即时**把简单形状“渲染成你想要的东西”，并强调实时反馈与时间一致性（identity/style 的稳定）



### 4、如果从0到1复刻类似产品，参考的开源项目
####  ✅ComfyUI（最核心参考）**GitHub**: `comfyanonymous/ComfyUI`
ComfyUI 是目前最强大的开源 node-based 生成式 AI 应用，用户可以通过在画布上连接节点来可视化构建复杂的 AI 工作流，与传统线性界面不同，它对生成过程的每一步都提供完整控制。 [15](https://www.earngenix.com/blog/why-learn-comfyUI) ComfyUI 给你一个空白画布，你通过连接"节点"（小型命名处理块）来组成 pipeline。每个节点做一件特定的事：加载模型、编码 prompt、采样图像、解码结果、保存文件。你把它们串联起来，这个视觉 pipeline 就是你的工作流

#### ✅ Vibe-Workflow（最直接的竞品开源复刻）**GitHub**: `SamurAIGPT/Vibe-Workflow`
Vibe Workflow 提供了一个可与 Krea Nodes 媲美的 node-based 编辑器，完全开源、可自定义，可接入任意 AI 后端。你可以用它构建可与 Freepik Spaces 媲美的 AI 图像生成 Pipeline，也可以像 Krea Workflows 一样排序和自动化视频生成任务。 [1](https://github.com/SamurAIGPT/Vibe-Workflow) 其技术栈为：`client/`（Next.js 前端）、`packages/workflow-builder/`（核心节点编辑器 UI 库）、`server/`（FastAPI 后端）


#### ✅OpenCanvas **GitHub**: `opencanvasai/OpenCanvas`
一个面向创作者的开源 node-based AI 工作流构建器，通过拖拽和连接画布上的积木块来构建复杂的 AI 工作流。 AI 模型——从图像生成到语言模型再到视频创作，只需插入你喜欢的模型即可开始创作
